Rnote 公式助手 — 使用说明
========================================

【它是干什么的】
  在 Rnote（或其他任何应用）里手写数学公式，按一个热键把公式框出来，
  立刻自动识别并计算：解方程、求导、积分、化简、因式分解……
  结果直接弹窗显示，主结果自动复制到剪贴板，直接 Ctrl+V 就能用。
  全程本地运行，不联网（除非你自己点 WolframAlpha 按钮）。

【热键】
  Ctrl+Alt+M         框选屏幕上的公式并计算（最常用；内置框选，不留文件）
  Ctrl+Alt+Shift+M   识别"剪贴板里已有的图片"（比如你已用 Win+Shift+S 截过图）
  Ctrl+Alt+Shift+Q   退出助手
  Esc                关闭结果弹窗
  托盘图标（右下角 fx）右键也有相同功能。

【怎么启动】
  1. 双击桌面上的「Rnote公式助手」快捷方式；
     或双击本目录里的「启动（无窗口）.vbs」；
     调试时用「启动（调试模式）.cmd」（能直接看到报错）。
  2. 右下角弹出"已就绪"提示后即生效，之后一直挂着即可。
  3. 开机自启（可选）：Win+R 输入 shell:startup 回车，
     把桌面的快捷方式复制进打开的文件夹。

【使用流程】
  1. 在 Rnote 里写好公式，例如  2x+7=15  或  x^2-5x+6=0
  2. 按 Ctrl+Alt+M → 屏幕变暗 → 拖动鼠标圈住公式（松手即完成；Esc 或右键可取消）
  3. 弹窗出现：
     - 上面显示"识别到的公式"（看不清就点重新框选）
     - 下面"="后是计算结果：解方程会给出 x = …；纯数字直接出结果
     - 一排按钮：求导 / 积分 / 解方程 / 化简 / 因式分解 / 展开 / 数值
       需要什么点什么，结果会追加到下方文本框
     - WolframAlpha：解不出来时点它，会复制 LaTeX 并打开网页接着算
  4. 主结果已自动复制到剪贴板；「复制 LaTeX」按钮可复制排版代码。

【识别小贴士】
  - 一次只框一个公式，别把旁边的文字、图形一起框进去（准确率最高）
  - 写得大一点、笔画清楚一点，识别率明显更高
  - 深色画布也能识别（程序会自动反色处理）
  - 识别错/算不对 → 点"重新框选"再来一次

【计算能力范围】
  一元方程求解、四则运算、分数、根式、求导、积分、化简、因式分解、展开、数值近似。
  超出范围或识别错：走 WolframAlpha 按钮。

【常见问题】
  - 热键没反应：确认助手在运行（托盘有 fx 图标）；没有就重新启动一次。
  - 卡住或报错：看本目录 rnote-ocr.log；调试模式窗口里也能看到。
  - 第一次识别要等十几秒：首次启动要加载识别模型，之后就快了。
  - 热键和别的软件冲突：编辑 config.json 修改（格式如 "ctrl+alt+m"），改完重启助手。
  - 换识别引擎：config.json 里 "ocr_engine"，默认 "pix2text"（手写识别更准）；
    可改 "pix2tex"（印刷体公式也行），改完重启助手。识别失败会自动换另一个引擎。
  - 不留文件：默认的"内置框选"直接内存截图，图片用完即释放：不写磁盘、不进剪贴板
    历史；剪贴板只会留下"结果文字"（方便直接粘贴）。想换回系统截图工具：把 config.json
    的 snip_method 改成 "ms-screenclip"（注意系统截图工具默认会把截图自动存到 图片\屏幕截图）。
  - Windows 用户名/路径：本项目假设安装在 C:\rnote-ocr，移动目录后请重建桌面快捷方式。

【文件说明】
  app.py            主程序（热键、截图、弹窗）
  pipeline.py       识别+计算管道
  config.json       配置（热键、是否自动复制等）
  .venv\            Python 虚拟环境（不要删、不要改）
  rnote-ocr.log     运行日志
  selftest_imgs\    自检测试图（可删）
  启动（无窗口）.vbs / 启动（调试模式）.cmd / 退出助手.cmd

【卸载】
  删除整个 C:\rnote-ocr 文件夹和桌面快捷方式即可，不留残余。
