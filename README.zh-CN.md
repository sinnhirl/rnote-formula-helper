# Rnote 公式助手 — 使用说明

在 Rnote（或其他任何应用）里手写数学公式，按一个热键把公式框出来，
立刻自动识别并计算：解方程、求导、积分、化简、因式分解……
结果弹窗显示，主结果自动复制到剪贴板，直接 Ctrl+V 就能用。
全程本地运行，不联网（除非你自己点 WolframAlpha 按钮）。

> English README: [README.md](README.md)

## 热键（默认值，可改）

| 热键 | 作用 |
| --- | --- |
| `Ctrl+Alt+Shift+M` | 框选屏幕上的公式并计算（最常用；内置框选，不留文件） |
| `Ctrl+Alt+Shift+C` | 识别"剪贴板里已有的图片"（比如你已用 Win+Shift+S 截过图） |
| `Ctrl+Alt+Shift+Q` | 退出助手 |
| `Esc` | 关闭结果弹窗 |

为什么默认用 Ctrl+Alt+Shift？因为 `Ctrl+Alt+M` 这类组合常被别的软件占用
（比如 NVIDIA GeForce Experience 就拿它当麦克风开关）；三个默认组合都经过
实测确认无冲突。被占用了也不要紧——下面教你随时改。

托盘图标（右下角 fx）右键也有相同功能。

## 修改快捷键 & 切换语言（弹窗右上角）

结果弹窗的**右上角**有两个小按钮：

- **快捷键** → 打开设置框 → 每行点「修改」→ 直接按下想要的新组合键
  （比如 `Ctrl+Alt+Shift+E`）→ 点「保存」，**立即生效、无需重启**。
  设置框里还有「恢复默认」一键还原，乱按了按 Esc 取消即可。
  也支持纯修饰键组合（比如只用 `Ctrl+Alt+Shift` 三个键）：录好后按住再松开即触发，
  它会等 0.35 秒确认你没继续按别的键（+C / +Q 不受影响）。
- **language** → 点击即切换整个界面语言（弹窗、设置框、
  托盘菜单、小提示都会跟着变），立即生效。

不想用界面也可以直接编辑 `config.json` 里的 `hotkey` / `language`（改完重启）。

## 启动与退出

1. 双击桌面上的「Rnote Formula Helper」快捷方式；
   或双击本目录里的 `start_silent.vbs`（无窗口运行）。
2. 调试用 `start_debug.cmd`（有窗口，能直接看到报错和日志）。
3. 退出：托盘图标右键 → 退出；或双击 `quit.cmd`；或按 `Ctrl+Alt+Shift+Q`
   （可在设置里改）。
4. 开机自启（可选）：Win+R 输入 `shell:startup` 回车，
   把桌面的快捷方式复制进打开的文件夹。

## 使用流程

1. 在 Rnote 里写好公式，例如 `2x+7=15` 或 `x^2-5x+6=0`
2. 按 `Ctrl+Alt+Shift+M` → 屏幕变暗 → 拖动鼠标圈住公式（松手即完成；
   Esc 或右键取消）
3. 弹窗出现：
   - 上面显示"识别到的公式"（看不清就点重新框选）
   - 下面"="后是计算结果：解方程会给出 `x = …`；纯数字直接出结果
   - 一排按钮：解方程 / 求导 / 积分 / 化简 / 因式分解 / 展开 / 数值
     需要什么点什么，结果会追加到下方文本框
   - 右上角：改快捷键（快捷键）、切换中英文（language）
   - WolframAlpha：解不出来时点它，会复制 LaTeX 并打开网页接着算
   - 识别有小错（比如某个小上标）？点「编辑」直接改，改完「重新计算」立即出新结果
4. 主结果已自动复制到剪贴板；「复制 LaTeX」按钮可复制排版代码。

## 识别小贴士

- 一次只框一个公式，别把旁边的文字、图形一起框进去（准确率最高）
- 写得大一点、笔画清楚一点，识别率明显更高
- 公式分两行写也没关系（程序会自动拼成一行再计算）
- 深色画布也能识别（程序会自动反色处理）
- 小上标（比如 0.75² 的 ²）偶尔会被认错成 z、³ 等，重要结果扫一眼再复制
- 识别错/算不对 → 小错用弹窗「编辑」改；错太多就"重新框选"再来一次

## 常见问题

- 热键没反应：确认助手在运行（托盘有 fx 图标）；没有就重新启动一次。
- 卡住或报错：看本目录 `rnote-ocr.log`；`start_debug.cmd` 窗口里也能看到。
- 第一次识别要等十几秒：首次启动要加载识别模型，之后就快了（<1 秒）。
- 热键和别的软件冲突：弹窗右上角「快捷键」里直接改（立即生效），
  或编辑 `config.json`（格式如 `"ctrl+alt+shift+e"`，改完重启助手）。
- 换识别引擎：`config.json` 里 `"ocr_engine"`，默认 `"pix2text"`（手写识别更准）；
  可改 `"pix2tex"`（印刷体公式也行），改完重启助手。识别失败会自动换另一个引擎。
- 不留文件：默认的"内置框选"直接内存截图，图片用完即释放：不写磁盘、不进剪贴板
  历史；剪贴板只会留下"结果文字"。想换回系统截图工具：把 `config.json` 的
  `snip_method` 改成 `"ms-screenclip"`（注意系统截图工具默认会把截图自动存到
  图片\屏幕截图）。
- 移动目录：本项目用相对路径，整个文件夹可以搬走；只有桌面快捷方式需重建
  （运行 `make_icon_and_shortcut.ps1`）。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `app.py` | 主程序（热键、截图、弹窗、快捷键/语言设置） |
| `pipeline.py` | 识别 + 计算管道 |
| `config.json` | 配置（热键、语言、引擎、是否自动复制等） |
| `start_silent.vbs` | 启动（无窗口，日常用这个） |
| `start_debug.cmd` | 启动（调试模式，有窗口能看到报错） |
| `quit.cmd` | 退出助手 |
| `.venv\` | Python 虚拟环境（不要删、不要改） |
| `rnote-ocr.log` | 运行日志 |
| `selftest_imgs\` | 自检测试图（可删） |
